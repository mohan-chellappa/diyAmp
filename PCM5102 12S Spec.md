PCM5102 I2S Digital Audio DAC Decoder Module - 3.5mm Stereo Output 

The PCM5102 DAC I2S Interface Decoder Sound Card Board, also known as the GY-PCM5102 Phat Format Player Module, is a compact and high-performance digital audio solution designed specifically for the Raspberry Pi and other I2S-compatible devices. This module utilizes the PCM5102 DAC chip, renowned for its high-quality audio conversion capabilities

The PCM5102 DAC I2S Interface Decoder Sound Card Board is ideal for anyone looking to enhance their Raspberry Pi’s audio capabilities. Whether you're building a custom media player, a DIY audio project, or an advanced audio system, this module provides an easy and effective solution for achieving high-quality digital-to-analog audio conversion.

**Features**

* The DAC Module provides a super affordable high-quality DAC for the Raspberry Pi.
* High-Quality Audio Output
* I2S Interface
* Phat Format Compatibility
* 3.5mm Stereo Output
* Wide Range of Compatibility

**Specifications**

* Model: GY-PCM5102
* DAC Chip: PCM5102A
* Form Factor: Phat (compatible with Raspberry Pi and other I2S devices)
* Audio Output: 3.5mm stereo jack
* input Interface: I2S 3pin
* Audio Data rate 16-, 24-, And 32-Bit
* Power supply: 5V

**Applications**

* A / V Receiver
* DVD, BD player
* HDTV receiver
* Applications Require 2VRMS audio output

**Package Includes**

* 1x PCM5102 I2S Digital Audio DAC Decoder Module
* 1x Pin Header
